# SpendWise — Personal Expense Tracker

## 1. Project Name

SpendWise

## 2. Project Description

SpendWise is a full-stack personal expense tracking web application that allows users to record, manage, and monitor their daily expenses.

The application will provide users with a simple dashboard where they can add expenses, view their expense history, update existing expenses, delete expenses, and see basic spending statistics.

## 3. Target Users

SpendWise is designed for students and individuals who want a simple way to keep track of their personal spending.

## 4. Core Features

### 1. User Authentication

Users can register, log in, and securely access their personal expense data.

### 2. Add Expenses

Users can add an expense with an amount, category, description, and date.

### 3. Manage Expenses

Users can view, edit, and delete their expenses.

### 4. Dashboard

Users can see total spending and basic expense statistics.

### 5. Responsive Interface

The application will provide a responsive interface that works on desktop, tablet, and mobile screens.
